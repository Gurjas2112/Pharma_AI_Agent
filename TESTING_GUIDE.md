# Quick Testing Guide

## 🚀 How to Test the Enhanced PharmaAI System

### Step 1: Verify Server is Running
```powershell
# Check if backend is running
Get-Process | Where-Object {$_.ProcessName -like "*python*"}

# If not running, start it
cd backend
uvicorn main:app --reload --port 8000
```

### Step 2: Open Frontend
1. Navigate to: http://localhost:3000
2. You should see the PharmaAI chat interface

### Step 3: Test with Sample Query

**Recommended First Test:**
```
Evaluate Montelukast as a repurposing candidate for cancer therapy
```

**Expected Behavior:**
- Bot processes query through all agents
- No premature "NO_GO" blocking
- Generates report with charts
- Creates PDF with logo splash screen

### Step 4: Verify Report Generation

Check the following files are created:
```powershell
# Navigate to reports directory
cd C:\Users\harpr\OneDrive\Desktop\Pharma_AI_Agent\backend\reports

# List generated reports
Get-ChildItem -Filter "PharmaAI_Report_*"

# Check charts directory
Get-ChildItem charts -Filter "*.png"
```

**Expected Files:**
- `PharmaAI_Report_[ID].pdf` - Main report with logo and charts
- `PharmaAI_Report_[ID].md` - Markdown version
- `charts/market_[ID].png` - Market size bar chart
- `charts/patent_[ID].png` - Patent expiry histogram
- `charts/clinical_[ID].png` - Clinical phase pie chart
- `charts/exim_[ID].png` - Import dependency heat map

### Step 5: Inspect PDF Report

Open the generated PDF and verify:

**✓ Page 1: Splash Screen**
- [ ] App_logo.png is centered and visible
- [ ] Title: "PharmaAI Research Report"
- [ ] Subtitle: "Innovation Opportunity Assessment"
- [ ] Molecule name displayed
- [ ] Generation timestamp shown

**✓ Page 2: Executive Summary**
- [ ] Decision box is present (GO/NO_GO/REVIEW)
- [ ] Decision box has correct color (Green=GO, Red=NO_GO, Orange=REVIEW)
- [ ] Confidence score displayed
- [ ] Reasoning text is readable

**✓ Pages 3-5: Analytics**
- [ ] Market size bar chart is embedded
- [ ] Patent expiry histogram is embedded
- [ ] Clinical phase pie chart is embedded
- [ ] Import dependency heat map is embedded
- [ ] Charts are high resolution (300 DPI)
- [ ] Charts have proper labels and legends

**✓ Pages 6+: Detailed Findings**
- [ ] Market Intelligence section present
- [ ] Patent Landscape section present
- [ ] Clinical Trials section present
- [ ] Web Intelligence section present
- [ ] Error messages shown gracefully if data unavailable

**✓ Last Page: Footer**
- [ ] Copyright notice present
- [ ] "Generated by PharmaAI" text visible

### Step 6: Test Error Resilience

**Test Query with Limited Data:**
```
Evaluate XYZ123NotARealMolecule for diabetes
```

**Expected Behavior:**
- Bot should NOT crash
- Should process query through all agents
- Agents return errors gracefully
- Report still generated with available data
- No "NO_GO" blocking on missing data

### 🐛 Troubleshooting

#### PDF Not Generating?
```powershell
# Check dependencies
pip list | Select-String -Pattern "matplotlib|reportlab|pillow"

# If missing, install
pip install matplotlib reportlab pillow
```

#### Logo Not Showing?
```powershell
# Verify logo exists
Test-Path "C:\Users\harpr\OneDrive\Desktop\Pharma_AI_Agent\App_logo.png"

# If False, check logo location and update path in report_agent.py
```

#### Charts Not Embedded?
```powershell
# Check charts directory exists
Test-Path "C:\Users\harpr\OneDrive\Desktop\Pharma_AI_Agent\backend\reports\charts"

# Create if missing
New-Item -ItemType Directory -Force -Path "backend\reports\charts"
```

#### Server Errors?
```powershell
# Check server logs
cd C:\Users\harpr\OneDrive\Desktop\Pharma_AI_Agent\backend

# Restart server with verbose logging
uvicorn main:app --reload --port 8000 --log-level debug
```
